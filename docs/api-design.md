# API Design

## Base URL
`/api/v1`

Set by `api_prefix` in `backend/app/core/config.py`. The frontend's
`NEXT_PUBLIC_API_URL` must include this prefix.

Responses are camelCase; request bodies are camelCase too (see
`app/schemas/base.py`). Interactive docs: `http://localhost:8000/docs`.

## Slugs

Constituencies and parties are addressed by a name-derived slug
(`worcester`, `liberal-democrat`) as well as by their database id. Slugs are
generated by `app/utils/helpers.py::slugify` and are what the frontend routes
on, since the static export cannot know database ids at build time.

## Endpoints

### Parties
- `GET /parties` – list all parties (`?year=` to pick the election year used for seat counts)
- `GET /parties/by-slug/{slug}` – party by slug
- `GET /parties/{id}` – party details
- `GET /parties/{id}/history` – seats and vote share per election year
- `GET /parties/{id}/constituencies` – seats held (`?year=`)
- `POST /parties` · `PUT /parties/{id}` · `DELETE /parties/{id}`

### Constituencies
- `GET /constituencies` – list (`?region=`, `?country=`, `?year=`)
- `GET /constituencies/by-slug/{slug}` – constituency by slug
- `GET /constituencies/{id_or_slug}` – details (`?year=`)
- `GET /constituencies/{id_or_slug}/results` – full results (`?year=`)
- `GET /constituencies/{id_or_slug}/prediction` – prediction, 404 if none exists

### Elections
- `GET /elections` – available election years
- `GET /elections/{year}/results` – all results for a year
- `GET /elections/{year}/summary` – national seat and vote-share summary
- `GET /elections/{year}/regions` – per-region winner breakdown
- `POST /elections/results`

### Polling
- `GET /polling` – time series (`?start=`, `?end=`, `?party_id=`)
- `GET /polling/latest` – latest figure per party
- `POST /polling`

### Predictions
- `GET /predictions` – all predictions (`?model=`)
- `GET /predictions/{constituency_id}` – prediction for a constituency
- `POST /predictions`

## Notes

Predictions are only generated for seats seeded as marginals, so
`/constituencies/{id}/prediction` returns 404 for most seats. The frontend
treats that as "no prediction" rather than an error.
